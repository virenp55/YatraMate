# ✈️ YatraMate

### Your Smart Travel Planner for India

YatraMate is a responsive UI/UX design concept for an Indian travel planning platform that helps users discover destinations, plan trips, create itineraries, and estimate travel budgets in one simple experience.

---

## 📌 About the Project

YatraMate is a **UI/UX design project created in Figma** for making Indian travel planning simple and convenient.

The platform allows users to explore popular Indian destinations, create personalized travel plans, manage their trip budget, and discover travel experiences.

The design focuses on **simplicity, responsive layouts, Indian travel aesthetics, accessibility, and user-friendly navigation**.

---

## 🎯 Project Goals

- Create a simple Indian travel planning experience.
- Help users discover popular destinations.
- Allow users to create personalized trip plans.
- Provide estimated trip budget information.
- Organize travel information in one place.
- Create responsive designs for Desktop, Tablet, and Mobile.
- Maintain consistent colors, typography, spacing, and components.

---

## 📱 Responsive Design

The YatraMate design is created for three different screen sizes:

1. **Desktop** — 1440 × 1024
2. **Tablet** — 768 × 1024
3. **Mobile** — 390 × 844

The layouts are adapted for each screen size instead of simply scaling the desktop design.
